# Markdown 规范（含省 token 写法）

## 目标
- 可读、可维护、可检索
- 内容可直达结论，避免重复

## 目录与文件命名
- 目录：`docs/` 统一收敛
- 文件：`NN-TITLE.md`（两位序号 + 大写连字符）
- 仅当需要记录决策时使用 `docs/adr/`

## 写作结构
- 每个文档固定三段：**目的**、**范围**、**要点**
- 先结论后展开：在开头给出 3~5 条关键结论
- 一文一主题：避免混写不同主题

## 格式与样式
- 标题层级不超过 3 级
- 列表优先用短句；一条只表达一个事实
- 代码块只保留最小可运行或最小可理解片段
- 表格用于对比；否则用列表

## 省 token 写法（重点）
- **避免上下文重复**：引用文档名或章节号，不重复整段
- **用引用代替复制**：跨文档用 “见 `docs/xx`”
- **删掉“显然/无需说明”等废话**
- **参数列举用范围**：如 `1~5`、`A/B`
- **变更记录用差异**：只写变更点而非全文
- **示例最小化**：仅保留一个代表性例子

## 建议模板
- 新文档从 `docs/templates/ADR-0000-template.md` 或本文档结构复制
- 统一在文末写“相关链接”区
