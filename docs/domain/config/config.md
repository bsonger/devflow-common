# Config

## 总配置
- `server` / `mongo` / `log` / `otel` / `repo` / `consul` / `pyroscope` / `env`

## MongoConfig
- `uri` 连接串
- `db` 数据库名

## OtelConfig
- `endpoint` OTEL 端点
- `service_name` 服务名

## Consul
- `address` Consul 地址
- `key` 配置 Key

## Repo
- `address` 仓库地址
- `path` 仓库路径
